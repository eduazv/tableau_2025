# tableau_2025
Course of Tableau 2024.3

In this course we have the original Tableau 2024.3 example files. that come with the Tableau Desktop installation file.

The Tableau 2025 installation file is available on the tableau website https://prerelease.tableau.com/ . 
There, if you register, you can get test licenses. 
As it has not been officially launched, the course is based on the latest production version of Tableau, which is located at https://www.tableau.com/pt-br/support/releases
